# Text Processing Tool

A Python tool for processing and analyzing English sentences.

## Features

- Validates English text input
- Removes selected text
- Removes numbers connected to letters
- Finds the longest word
- Counts words, letters, and numbers
- Allows multiple sentences to be processed

## Technologies

- Python
- String Manipulation
- Loops
- Conditional Statements
- Input Validation
- String Module

## About

This project was created as part of my Python programming practice.
It helped me improve my skills in string manipulation, loops, conditional statements, input validation, and text analysis.
